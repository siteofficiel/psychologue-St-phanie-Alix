ESPACE ADMINISTRATEUR DU BLOG (INTÉGRÉ À BLOG.HTML)
---------------------------------------------------
- Ouvrez la page blog.html.
- Tout en bas, cliquez sur le lien discret « Espace admin ».
- Mot de passe : Zack2026

L'espace admin s'ouvre DANS la même page (aucune page séparée, donc
aucune page « introuvable »). Il permet d'AJOUTER et de SUPPRIMER des
articles du blog, sans toucher au code.

Les articles ajoutés sont enregistrés dans le navigateur (stockage
local) : ils apparaissent immédiatement sur le blog de ce navigateur.

A SAVOIR : sans serveur, les modifications sont propres à l'appareil
utilisé. Pour que les articles ajoutés soient visibles par TOUS les
visiteurs du site, un petit module serveur (PHP) est nécessaire —
demandez-le nous si besoin.

COMMENT PUBLIER LE SITE
-----------------------
1. Décompressez entièrement cette archive (clic droit > "Extraire tout").
2. Envoyez TOUT le contenu (les 8 fichiers .html + logo.png + le dossier
   images + articles.json) à la racine de votre hébergement web.
3. La page d'accueil doit s'appeler "index.html" : elle s'ouvrira
   automatiquement quand on visite votre nom de domaine.
