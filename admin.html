Comment publier mes articles ?
Vos articles sont enregistrés dans ce navigateur (stockage local) et apparaissent aussitôt sur votre blog, sur cet appareil. Pour que tous les visiteurs les voient :
  1. Cliquez sur Exporter articles.json ci-dessous ;
  2. Déposez le fichier téléchargé dans le même dossier que blog.html sur votre hébergement (FTP / gestionnaire de fichiers) ;
  3. C'est publié ! (Refaites l'export à chaque modification.)
